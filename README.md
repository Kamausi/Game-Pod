# Game-Pod

## 🎃 Haunted Harvest
A Halloween arcade game in a single HTML file: [`haunted-harvest/index.html`](haunted-harvest/index.html). Open it in any browser to play.

- Fly your witch around the graveyard and collect candy.
- Dodge the ghosts that chase you and the bats that swoop past.
- Grab a 🎃 pumpkin to scare the ghosts, then fly into them for bonus points.
- Every 20-second wave rolls a random curse: fog, reversed controls, giant ghosts, a blood moon, candy rain and more.

Controls: mouse/touch or arrow keys/WASD · `P` pause · `M` mute
